## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd <project-directory>
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   ```

3. **Set up EmailJS** (Required for contact form)
   - Follow instructions in `EMAILJS_SETUP.md`
   - Update credentials in `/src/app/components/Contact.tsx`

4. **Add your resume** (Optional)
   - Place `resume.pdf` in `/public` directory
   - See `public/README_RESUME.txt` for details

## 🚀 Running the Project

The Vite dev server is already running in this environment. Simply view the preview to see your changes.

For local development:
```bash
pnpm install
```

The dev server will start automatically. Do NOT run `vite` or `npm run dev` manually.

## 📝 Customization Guide

### Update Personal Information

1. **Name and Branding**
   - Update in `/src/app/components/Hero.tsx`
   - Update in `/src/app/components/Navigation.tsx`
   - Update in `/src/app/components/Footer.tsx`

2. **Contact Information**
   - Email: Update in `/src/app/components/Contact.tsx`
   - Social links: Update in `/src/app/components/Footer.tsx`

3. **Projects**
   - Edit project data in `/src/app/components/Projects.tsx`
   - Add your GitHub repository links
   - Update project descriptions and stats

4. **Skills**
   - Modify skill list in `/src/app/components/TechStack.tsx`
   - Adjust proficiency percentages
   - Change color gradients

5. **About/Roadmap**
   - Update journey phases in `/src/app/components/About.tsx`
   - Customize your vision statement

### Color Scheme

The default color scheme uses:
- Primary: Blue (#3B82F6)
- Secondary: Cyan (#22D3EE)
- Accent: Purple, Pink, Orange, Green gradients

To customize:
- Update gradient classes in component files
- Modify Tailwind color usage
- Adjust theme in `/src/styles/theme.css`
